# Лабораторная работа 2: ETL процесс для SQLite

## Описание
Данная утилита автоматизирует процесс ETL (Extract, Transform, Load) для переноса исходных данных из текстовых файлов (CSV/TXT) в реляционную базу данных SQLite.

## Требования к окружению
Для корректной работы скрипта `db_init.bat` на вашем компьютере должны быть установлены:
1. **Python 3.x** (для запуска утилиты генерации SQL-скрипта).
2. **SQLite3** (консольная утилита должна быть доступна в переменной окружения PATH).

## Структура файлов
- `dataset/` — папка с исходными файлами (`movies.csv`, `ratings.csv`, `tags.csv`, `users.txt`).
- `make_db_init.py` — Python-скрипт, генерирующий оптимизированный SQL-код.
- `db_init.sql` — генерируемый SQL-скрипт (содержит CREATE TABLE и быстрый импорт через `.import`).
- `db_init.bat` — кроссплатформенный shell-скрипт для запуска всего процесса.

Выполните в терминале (Git Bash / Linux / macOS):
