# Task 01: Подготовка данных и знакомство с SQLite

## Описание структуры файлов данных

В данной папке находятся следующие файлы:

### Исходные данные:
1. **movies.csv** — таблица с информацией о фильмах (movieId, title, genres).
2. **ratings.csv** — таблица оценок, поставленных пользователями фильмам (userId, movieId, rating, timestamp).
3. **users.txt** — таблица с данными о пользователях (userId, имя, email, пол, дата регистрации, профессия).
4. **occupation.txt** — справочник возможных профессий пользователей.
5. **tags.csv** — таблица с тегами, которые пользователи присваивают фильмам (userId, movieId, tag, timestamp).

### Сгенерированные файлы:
6. **ratings_count.txt** — текстовый файл, содержащий статистику: минимальный и максимальный `userId` из файла `ratings.csv` и количество строк (оценок), связанных с каждым из этих идентификаторов.
7. **sqlite.txt** — текстовый файл, содержащий информацию об установленной версии СУБД SQLite и список доступных режимов вывода данных в консольном клиенте `sqlite3`.
